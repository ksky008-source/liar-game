# 라이어게임

4~8명이 각자 휴대폰·PC로 접속해 실시간으로 함께 하는 온라인 라이어게임입니다.

**MADE BY KIMJIHUN**

## 모드
| 모드 | 인원 | 규칙 |
|---|---|---|
| 노멀모드 | 4~8명 | 라이어 1명만 제시어를 모릅니다. 라이어가 지목되면 제시어를 맞힐 기회를 받고, 맞히면 라이어 승리·틀리면 시민 승리. 시민이 지목되면 라이어 승리. |
| 바보모드 | 4~8명 | 바보 1명은 비슷하지만 다른 제시어(예: 사과 ↔ 배)를 받고, 결과 전까지 자신을 시민으로 압니다. 바보가 지목되면 시민 제시어를 맞힐 기회 → 맞히면 바보 역전승, 틀리면 시민 승리. 다른 사람이 지목되면 바보 승리. |
| 스파이모드 | 5~8명 | 스파이는 제시어와 라이어를 알고 라이어를 돕습니다(라이어·스파이 한 팀). 라이어가 지목돼 정답을 못 맞히면 시민 승리, 그 외에는 라이어·스파이 진영 승리. |

공통 진행: 방 생성(모드 선택) → 초대 링크/코드로 참가 → 좌석 순서대로 두 라운드 한 줄 설명 → 비밀 투표(동점이면 무작위) → 최종 추측 → 결과 공개(정답·역할·투표).

## 구성
- `server.js` — 게임 서버 (Node.js 18+, 추가 패키지 없이 실행). 역할 배정·차례·투표·승패 판정을 모두 서버가 처리하고, 각 사람에게 본인 정보만 보냅니다. 참가 토큰은 SHA-256 해시로만 저장합니다.
- `words.js` — 제시어 목록과 바보모드 제시어 쌍.
- `index.html` — 게임 화면 (한국어, PC·모바일 반응형).
- `test.js` — 자동 테스트: 모든 모드를 4~8명으로 실제 서버에 접속해 끝까지 진행 (`npm test`).
- `jsconfig.json` — 타입 검사 설정 (`npm run typecheck`).

## Render 배포 설정
| 항목 | 값 |
|---|---|
| Language | Node |
| Branch | main |
| Build Command | `npm install` |
| Start Command | `npm start` |
| Instance Type | Free |

GitHub `main`에 새 코드가 올라오면 Render가 자동으로 다시 배포합니다.

## 알아 둘 점
- 게임 상태는 서버 메모리에 있습니다. 서버가 재시작되면 진행 중인 방은 사라집니다.
- Render 무료 플랜은 15분 동안 접속이 없으면 잠들고, 다음 첫 접속에 30~50초가 걸립니다.
- GitHub Pages는 정적 파일만 제공하므로 실시간 게임 서버를 실행할 수 없습니다. 그래서 코드는 GitHub에, 실행은 GitHub와 연결된 Render에서 합니다.
