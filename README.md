# 라이어 테이블 (liar-game)

친구 4명이 각자 휴대폰·PC로 접속해 실시간으로 함께 하는 온라인 라이어게임입니다.

## 게임 흐름
1. 닉네임을 쓰고 방을 만들면 5자리 초대 코드와 초대 링크가 생깁니다.
2. 4명이 모이면 방장이 시작합니다. 서버가 카테고리와 제시어를 고르고, 시민 3명·라이어 1명을 무작위로 정합니다.
3. 1번 → 4번 순서로 한 줄씩, 두 라운드 설명합니다.
4. 비밀 투표 → 최다 득표자 지목 (동률이면 무작위).
5. 지목된 사람이 라이어면 제시어를 맞힐 마지막 기회가 있습니다. 끝나면 역할·정답·투표가 모두 공개됩니다.

## 구성
- `server.js` — 게임 서버 (Node.js 18 이상, 추가 설치 패키지 없음). 방·역할·설명·투표·판정을 모두 서버에서 처리하고, 각 사람에게 자기 정보만 보냅니다.
- `index.html` — 게임 화면 (한국어, 반응형).
- `test.js` — 4명 자동 테스트 (`npm test`).

## Render 배포 설정
| 항목 | 값 |
|---|---|
| Language | Node |
| Branch | main |
| Build Command | `npm install` |
| Start Command | `npm start` |
| Instance Type | Free |

## 알아 둘 점
- 게임 데이터는 서버 메모리에 있습니다. 서버가 재시작되면 진행 중인 방은 사라집니다.
- Render 무료 플랜은 15분 동안 접속이 없으면 잠들고, 다음 첫 접속에 30~50초가 걸립니다.
